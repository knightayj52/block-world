# 모아섬 | 영쌤클래스
휴대폰과 태블릿용 1인칭 블록 건축 게임입니다. 압축 파일의 **모아섬-체험.html**을 브라우저에서 열면 단독 체험을 할 수 있습니다. 모바일 파일 미리보기 앱은 스크립트 실행을 제한할 수 있어 Pages 주소로 접속하는 방법을 권장합니다.

## GitHub Pages
1. 새 저장소 `block-world`를 만들고 압축을 푼 소스의 docs, server, Dockerfile, README.md를 저장소 루트에 넣습니다.
2. Settings → Pages → Deploy from a branch → main → /docs → Save.
3. Pages에 표시된 주소로 접속합니다. docs 안의 파일은 모두 함께 배포해야 합니다. 서버 설정 전에는 기기별 연습 월드가 실행됩니다.

## 학급 서버
영구 디스크가 있는 Python 또는 Docker 서버 한 개를 사용합니다. 학급당 서버 하나이며, 학생은 선생님이 배포한 학급 코드로 별명을 등록합니다. 실명·이메일은 필요하지 않습니다. 운영환경에서는 HTTPS를 사용하세요.

로컬 PC에서는 저장소 루트에서 아래 명령을 실행하고 http://localhost:8080 에 접속합니다. 같은 서버를 다시 시작할 때 같은 DB 파일을 사용합니다.
```sh
python -m pip install -r server/requirements.txt
read -rsp '학급 코드 입력: ' CLASS_CODE
export CLASS_CODE
python server/app.py
```

Docker 운영 시 이미지 빌드 후 영구 볼륨을 /data 에 마운트하고 CLASS_CODE를 호스팅 서비스의 비밀 환경변수로 지정합니다. PAGES_ORIGIN 은 Pages의 출처(예: https://knightayj52.github.io, 경로와 마지막 슬래시 제외)로 지정합니다. 서버의 HTTPS 주소를 docs/config.js 의 SERVER_URL 에 입력하고 Pages에 반영합니다. 공용 기기에서는 사용 후 월드 메뉴에서 로그아웃합니다. 비밀번호와 학급 코드는 저장소에 올리지 않습니다.

## 수업 전 두 기기로 확인하기
- A기기에서 가입한 뒤 블록을 놓고 서버 저장 완료를 확인합니다. B기기에서 같은 아이디로 로그인해 같은 위치·소지품·블록을 확인합니다. 이전 기기는 다음 요청에서 로그인이 풀립니다.
- 서로 다른 계정 두 개를 사용합니다. 내 월드 → 월드 메뉴 → 학급 월드 → 친구 아이디 → 건축 초대. 친구는 초대 새로고침 → 해당 월드 선택 → 선택한 월드 열기. 초대는 가입된 계정 단위로 유지됩니다.
- 구경 권한에서는 건축할 수 없습니다. 월드 주인이 친구 아이디로 초대를 종료할 수 있습니다.
- 서버는 약 0.85초 간격으로 위치와 월드 변경 사항을 동기화합니다. 채굴·건축·제작은 서버 확인 후 반영합니다. 연습 월드와 학급 월드의 진행 기록은 별개입니다.

## 교사용 월드 복구
서버 콘솔에서 운영 서버와 같은 WORLD_DB를 설정한 상태로 실행합니다. 파일에는 선택한 월드의 블록·학생별 위치·소지품이 들어갑니다. 서버 공용 웹 폴더 밖에 보관하세요. 복구는 학생들이 나간 뒤 서버를 정지하고 실행합니다.
```sh
python server/checkpoint.py save 학생아이디 수업전.json
python server/checkpoint.py restore 학생아이디 수업전.json
```

## 0.2 월드와 건축
기기 월드는 이름과 지형을 정해 여러 개 만들 수 있습니다. 기존 0.1 저장 데이터는 같은 주소·브라우저에서 '기존 숲 월드'로 표시됩니다. 개별 HTML 파일의 저장 공간은 브라우저와 파일 경로에 따라 달라질 수 있습니다. 숲, 섬, 협곡은 각각 고정 지형입니다. 벽돌·유리·등불·표지판은 시작 꾸러미에 들어 있습니다. 표지판을 선택하고 ‘표지판 문구’를 입력한 뒤 놓으세요. 학급 월드는 처음 가입할 때 선택한 지형·이름을 사용하고, 이미 있는 학급 계정은 원래 지형에서 이어집니다. 초대받은 학생도 같은 표지판을 볼 수 있습니다.
작업대에서 나무·흙·모래·판자를 소모해 판자·벽돌·유리·등불·표지판을 추가 제작할 수 있습니다.
